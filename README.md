### Using behavioral cloning to play Flappy Bird

This repository contains scripts for:

* A basic version of the game
* Recording gameplay data of how a human plays the game
* Training a supervised learning model on the above data
* Using the model to play the game, imitating the human player

The gameplay history (and model) files are included in the repo to aid reproducibility of results.

Assets used: https://megacrash.itch.io/flappy-bird-assets (licensed under CC0)
